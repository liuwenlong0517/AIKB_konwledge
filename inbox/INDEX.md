# 候选知识

本目录是知识仓全局统一的未验证来源数据入口，不预先归属于 `knowledge/`、`experience/`、`workflows/` 或 `projects/`。新增来源卡片时使用控制仓 `%AIKB_HOME%/system/templates/inbox-entry.md`，记录来源、当前假设、待验证项、预期范围和下一步动作；经 LLM 整理并由人工完成查重、证据、适用范围和分类验证后，再分发到适当的正式目录，同时更新本索引、目标目录索引和知识仓根 `CATALOG.md`。已经明确目标分类、仅用于保留稳定入口的占位文档不属于 Inbox 来源卡片，可保留在对应正式目录并以 `status: candidate` 标识待完善。不要在此保存原始聊天记录或无上下文的临时想法。
